## 使用说明

- **来源**：[本目录教材](<Humangeographie kompakt.pdf>)，Tim Freytag、Hans Gebhardt、Ulrike Gerhard、Doris Wastl-Walter 编，Springer，2016，当前 PDF 共 197 页。按页筛查可提取的正文与图表文字，并补看人口金字塔、语言分布、绅士化模型、生产网络和生计框架等图表。按全书 8 章组织；书前材料、参考文献和末尾索引用于核对，不收录人名、地名、文献题名来凑词数。
- **去重基准**：[《Physische Geographie kompakt》模块词汇表](<../PhysischeGeographie/Physische Geographie kompakt_模块词汇表.md>)。已检查旧表词条栏中的单列词、斜线并列词及常见单复数变化；旧表已有的完整词条不再列出。新复合词如果表示独立的人文地理概念，仍会保留，即使其中某个构词成分已经学过。一本书内反复出现的同一词条只列一次。
- **页码全部指 PDF 阅读器页码**，从封面计为第 1 页，**不是纸面印刷页码**。本 PDF 省略了部分空白页，不能使用统一偏移量换算。定位页可包含词的单复数、屈折、直接相关派生形式；用连接号省略的复合词补全后列出。页码不一定是首次出现页。
- **A = 优先背诵**：影响主要概念理解或反复用于课堂论述；**B = 阅读识别**：较细的分类、专门理论词或低频表达。这是学习优先级，不是官方语言等级，也不代表这些词你都不认识。
- 德语名词给冠词；`Pl.` 表示复数，`Adj.` 表示形容词，`V.` 表示动词。少数书中直接使用的英语、拉丁语术语也保留，并标明语言。中文释义按本书语境写，尤其注意日常义与学术义的区别。
- **拆解用于记忆，不等于逐字直译或完整词源学说明**。`+` 表示构词成分；连接音通常没有独立意思；复合名词末尾的名词通常决定冠词。标为“联想”“词族”的提示不是严格词源。无法可靠拆分的外来词按整体记忆。
- 这是适合预习的筛选词表，不是全文翻译或所有生词的穷尽清单。书中历史思想、移民身份和政策表达按教材语境解释；本表不更新教材中的制度或统计事实。

## 易混概念：背完后用来检验理解

| 概念组 | 区分重点 |
| --- | --- |
| Translokalität / Multilokalität | 前者强调地方之间由流动形成的联系；后者强调个人或家庭的生活同时分布在多个地方。两者可重叠。 |
| Prekarität / Deprivation / Exklusion | 分别重在“不稳定”“资源或机会匮乏”“被排除在参与之外”，不是完全相同的贫困指标。 |
| Assimilation / Sozialintegration | 同化强调趋近主流社会的特征；社会融入关注参与与联系，不必然要求消除文化差异。 |
| Urbanität / Suburbanisierung / Reurbanisierung | 依次关注城市生活特征、向郊区转移、重新向城市核心集中；不要只凭共有的 urban- 混为一谈。 |
| Segregation / Polarisierung / Fragmentierung | 依次关注群体空间分离、差距扩大与两极分化、城市裂解为弱联系片段。它们可以同时发生。 |
| Territorialisierung / Territorialität | 前者是形成地域控制与边界的过程；后者是通过地域组织控制和归属的性质或方式。 |
| Governance / Gouvernementalität / Hegemonie | 依次侧重治理安排、塑造行为的治理理性与技术、社会关系中的主导地位。 |
| Wertschöpfungskette / globales Produktionsnetzwerk | 链条突出各环节及其协调；网络进一步凸显多方向联系、制度环境和不同主体的权力关系。 |
| Pfadabhängigkeit / Lock-in / Kontingenz | 历史选择约束后续发展；约束可强化为锁定；路径形成又常包含并非必然的偶然事件。 |
| Modernisierungstheorie / Dependenztheorie / Post-development | 分别突出从传统向现代的转变、不平等依附关系、对“发展”这一知识与干预框架本身的批判。 |
