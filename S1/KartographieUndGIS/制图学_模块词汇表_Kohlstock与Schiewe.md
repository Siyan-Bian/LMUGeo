# 制图学模块词汇表：Kohlstock 与 Jochen Schiewe

面向已达到 **DSH-2／德福 16**、准备阅读制图学教材的学习者。本表把两套教材合并为 **14 个模块、468 个词条组**：A 类 390 组，B 类 78 组。一行可能包含同义词、对照词或同一概念的常见形式，不把每个变体另算一条。另附 **71 组相关词辨析**，方便区分使用场景。

## 使用方式与筛词范围

- **A：优先背。** 阅读地图投影、测量、符号设计、专题制图和 GIS 时较常用的专业词，或日常词在制图学中的特殊含义。
- **B：第二遍背。** 较专门的仪器、排印、印刷、方法名称和历史制图词。A／B 是本表的学习优先级，不是官方语言等级。
- **构词拆解是记忆辅助。** 复合词尽量拆出词干；派生词标出有帮助的词根、前后缀。连接成分 `-s-`、`-n-`、`-en-` 通常不单独翻译。外来词、人名方法和缩写不强行编造德语词源。
- **英文列**：同一格先列英文对应词，再给英文词根、词缀、复合词拆解或词族提示。并列词按德语顺序对应，同义名称可共用英文。不能可靠拆分的整体记忆；描述性译法与词源联想会注明。英语以美式拼写为主，专业含义结合中文简译及相关词辨析理解。
- **先背简译，再看辨析。** 中文栏优先给简短、常用的译名；相关词并列给出德语和中文，再说明使用场景。基本同义的词明确说明，不为了区分而编造差异。
- **按原文用法解释。** 名词尽量给出冠词；`Pl.` 表示复数，`Adj.` 表示形容词，`V.` 表示动词。复数、屈折、断行连字符和省略式复合词可恢复为便于背诵的完整形式。例如 `Spinnen- oder Netz-Diagramm` 展开为两个完整词。
- **延续去重。** 已与[自然地理词表](<../PhysischeGeographie/Physische Geographie kompakt_模块词汇表.md>)和[人文地理词表](<../AnthropoGeographie/Humangeographie kompakt_模块词汇表.md>)比对，新词主体不重复列入旧表已收录的完整词条。为了辨析，旧词和常用词可以作为对照再次出现，不另计为新增词条。旧词构成的新复合词仍保留，如旧表的 `Ellipsoid` 与本表的 `Referenzellipsoid`。
- **检查范围。** 对下列 10 份 PDF 的全部 623 个文件页按页筛查可提取文字，并补看关键示意图、低文本图版；筛选目标是提前读懂教材，不收录所有普通词、地图上的地名、软件品牌或参考文献中的专名。已经成为方法术语的人名例外。

| großmaßstäbig／kleinmaßstäbig | 1∶10 000 比 1∶1 000 000 比例尺大，通常细节更多。 |
| Geoid／Referenzellipsoid | 重力场相关的物理参考面／规则的数学参考面。 |
| Äquidistanz／Scharung | 等高距是垂直高差；线在图面上挤得多密是另一件事。 |
| Orthodrome／Loxodrome | 球面最短航线／保持与经线交角不变的恒向线。 |
| Schraffe／Schraffur | 描绘地形坡面的短线／一般性的线状填充纹样。 |
| Punktstreuungskarte／Punktsignaturenkarte | 点代表规定数量／点位符号代表地理对象；散点未必就是对象精确位置。 |
| Choroplethenkarte／Anamorphotendarstellung | 主要改变区域填色／改变区域的面积和形状。 |
| Herstellergenauigkeit／Nutzergenauigkeit | 从参考真值的某类看“找回多少”／从地图所标的某类看“多少可信”。 |
