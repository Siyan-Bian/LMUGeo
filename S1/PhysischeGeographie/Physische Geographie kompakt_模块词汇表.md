# Physische Geographie kompakt：模块词汇与构词记忆

## 使用说明

- **来源**：本目录的《Physische Geographie kompakt》，Glaser 等著，Springer，当前 PDF 共 222 页。词汇按全书 13 章组织，逐页检查可提取的正文及图表文字，并补看文字提取不足的图像页；书前说明、参考文献和末尾索引用于核对，不把书名、人名、网址等凑入生词表。
- **页码全部指 PDF 阅读器页码**，从封面计为第 1 页，不是纸面印刷页码。PDF 省略了部分空白页，不能用固定加减数换算。表中页码是该词或其屈折形式、直接相关词形的定位页，不一定是全书首次出现页。
- **A = 优先背诵**：理解主要过程和课堂表述所需；**B = 阅读识别**：更细的分类、专门术语或低频表达。等级是本词表的学习优先级，不是官方 CEFR 等级，也不代表你一定不认识。
- 名词给出冠词；`Pl.` 表示以复数列出，`Adj.` 表示形容词，`V.` 表示动词。名词尽量还原为单数，书中常见的复数类别名称会保留。中文采用本章专业语境义。
- **拆解是记忆辅助，不是逐词直译**。`+` 分隔构词成分；连接音 `-s- / -n- / -en-` 一般不单独翻译；末尾名词通常决定复合名词的词性。`词族`、`联想`不等于严格词源。不能可靠拆分的词明确标为整体记忆。
- **英文列**：同一格先列对应英文，再用 `+` 或词族说明构词；短语按组成词拆解，不适合拆分的词整体记忆。并列词通常按德语顺序对应；同义词可能共用一个英文词。词源、拼写联想和描述性译法会另作标注。英语以美式拼写为主，英文解释与原中文释义共同限定使用场景。
- 这是一份筛选后的预习词表，不是全文翻译或所有陌生词的穷尽清单。一般生活词、透明且容易理解的基础表达不重复罗列；术语即使组成词很简单，只要专业义容易误解，仍然保留。

同一个熟词在不同模块可能换义：`Auflösung` 在遥感里是分辨率，`Fracht` 在河流里是所搬运的物质，`Sohle` 是河床或谷底，`Bestand` 在植被里是林分，`Vermögen` 可以是能力也可以是资产，`Vektor` 在 GIS 中是矢量、在健康风险段落中是传播媒介。

## 建议怎么背

1. **跟课程进度选模块**，先背该模块 A 类。已经认识的直接划掉，不必为了完成表格重复背。
2. 每个词做两次回忆：看德语说出中文专业义；遮住拆解栏，自己分解单词。复合词同时记最后一个名词及其冠词。
3. 把对照词一起背，例如 `Prallhang / Gleithang`；把过程串起来，例如 `Verwitterung → Transport → Ablagerung → Diagenese`。
4. 每轮回到表中的 PDF 页，确认该词用于什么过程或图示；B 类以阅读时能认出为目标。
